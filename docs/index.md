# ChatDemo · 网页作品目录

把已经生成的网页组织成可打开、可交互、可部署的作品目录。

<div class="grid cards" markdown>

- **本机看作品**

    安装后运行 `chatdemo serve`，打开内置机械原型。

    [进入作品说明](gallery.md)

- **接入自己的网页**

    用 `add` 注册静态目录，以固定路径供浏览器访问。

    [查看命令树](cli-tree.md)

- **导出完整站点**

    用 `export` 生成画廊及所有资源，再交给静态平台发布。

    [核对能力边界](capability-map.md)

- **从 Python 调用**

    直接调用目录、导出和服务函数，无需启动子进程。

    [查看接口树](interface-tree.md)

</div>

## 快速开始

```bash
python -m pip install -e .
chatdemo serve --port 8769
```

浏览器打开 `http://127.0.0.1:8769/`。服务默认只监听本机，按 Ctrl+C 停止。
