# 能力地图

<div class="grid cards" markdown>

- **作品目录**

    管理内置作品和显式注册的静态目录；元数据可输出为 JSON。

- **HTTP 画廊**

    默认只监听本机；仅提供画廊和注册根目录里的资源。

- **静态导出**

    复制所有页面与依赖，生成适合子路径托管的完整站点。

</div>

| 能力 | 范围 |
| --- | --- |
| 三种机械原型 | 内置 Three.js 依赖；旋转、速度、拆解、暂停、单步 |
| 自定义网页 | 注册已经构建完成、以 index.html 为入口的素材目录 |
| 访问边界 | 禁止路径穿越、隐藏文件、符号链接和目录列表 |
| 配置 | 作品注册表是应用数据；无 API 密钥需求；保留 ChatEnv schema 入口 |
| 文档作品入口 | 文档构建时导出内置画廊，生产和预览使用相同构建规则 |

## 约束

这是面向本机与可信素材的演示服务器，不提供认证、TLS、多用户写入或后端进程。目录不得混放凭据、私密文档和未准备公开的素材。带绝对资源 URL 的自定义网页需要自行改为适合目标部署的路径；导出不重写脚本。

浏览器需要支持 WebGL 才能运行机械页。机械是可观察的视觉原型，不代表真实机械已经制造或通过物理验证。
