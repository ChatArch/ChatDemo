# Demonstrations

The bundled Mechanical Atelier includes a Geneva wheel, double-pendulum escapement and planetary differential. All Three.js dependencies are included.

<div class="grid cards" markdown>

- **Online gallery**

    <a href="../../web/">Open the Web gallery →</a>

- **Local gallery**

    Run `chatdemo serve` and open `http://127.0.0.1:8769/`.

- **Custom work**

    Register a static page with `chatdemo add`, then restart the server.

</div>

## Mechanical controls

Choose a model on the left, drag the scene to rotate, adjust speed or explosion sliders, and pause to advance manually. These are visual designs; fabrication dimensions and physical forces require separate validation.
