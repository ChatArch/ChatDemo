# 作品入口

内置「机巧」包含六瓣星轮、双摆擒纵与行星差速，所有 Three.js 依赖随作品一起提供。

<div class="grid cards" markdown>

- **在线画廊**

    <a href="../web/">打开网页作品目录 →</a>

- **本机画廊**

    执行 `chatdemo serve`，打开 `http://127.0.0.1:8769/`。

- **自定义作品**

    执行 `chatdemo add` 注册自己的静态页面，再重启服务。

</div>

## 机械操作

选择左侧模型，拖动画面旋转视角，用滑块调整速度或拆解程度，按暂停后手动推进。页面展示机械视觉设计；制造参数和真实受力需要另行验证。
